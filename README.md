# DevOps Learning

My hands-on journey through DevOps engineering.

This repository contains my notes, experiments, practical exercises,
and troubleshooting cases while learning DevOps from fundamentals
to production-oriented technologies.

## Roadmap

- Git
- Linux
- SQL / PostgreSQL
- Docker
- CI/CD
- Ansible
- Kubernetes
- Monitoring & Logging
- Cloud
- Terraform
- Message Brokers
- GitOps
- Vault

## Philosophy

Learn → Practice → Break → Troubleshoot → Document

The goal is not just to memorize commands or tools,
but to understand how they work and why they are used.
